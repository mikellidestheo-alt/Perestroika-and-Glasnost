# Кабинет Генерального секретаря (1985–1991)

Интерактивная 3D-игра для изучения темы «Перестройка и гласность» (Pearson Edexcel A-Level Russian, Theme 4).
Вы – Генеральный секретарь в Кремле: принимайте пять исторических решений и следите за четырьмя показателями
(**Экономика, Гласность, Поддержка партии, Народное доверие**).

## Управление
- **Красная папка** – записка и выбор решения (после кризисного звонка).
- **Телефон «вертушка»** – звонит в кризис (Чернобыль, Афганистан); ответьте, чтобы открыть папку.
- **Терминал «Электроника»** – показатели, журнал решений, словарь ключевых терминов.
- **Газеты** – «Правда»/«Известия» отражают последствия решений.
- Подчёркнутые слова в тексте – термины: наведите курсор или нажмите для определения.
- Мышь – вращение камеры.

## Концовки
Победа (август 1991, баланс показателей) · путч консерваторов (Поддержка партии = 0) · экономический крах (Экономика = 0) ·
народное восстание (Доверие ≤ 20 при Гласности ≥ 50) · ГКЧП · чрезвычайное положение. Итоговый экран сравнивает ваши выборы с реальной историей.

## Разработка
```bash
npm install
npm run dev        # локальный сервер
npm run typecheck  # проверка TypeScript
npm run build      # продакшн-сборка в dist/
```

Стек: Vite, React, TypeScript, Three.js (`@react-three/fiber`, `@react-three/drei`), Zustand, Web Audio API (звуки генерируются кодом).
Игровые данные (сценарии, глоссарий, эффекты) – в `src/game/`.

## Деплой (GitHub Pages)
Workflow `.github/workflows/deploy.yml` при каждом push в `main` ставит Node 20, запускает `npm ci`, проверку типов и сборку и публикует `dist/`.
Один раз включите: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Сборка использует относительный `base`, поэтому работает и на Vercel.
